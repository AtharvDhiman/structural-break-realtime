What's really happening: when you change anything, the page generates a fresh stream and the detector scores every point in real time. It first measures how much this stream normally wiggles (from the grey history), then, for each new point, asks how far the running average and the running spread have drifted from that normal — in standard deviations — and squashes the answer to 0–1. A permanent break keeps pushing the drift up, so confidence climbs and stays; ordinary noise doesn't. This is a simplified cousin of the competition model — same two core ideas (judge each stream by its own history; let evidence accumulate) but without the AR+GARCH whitening or the trained combiner.
